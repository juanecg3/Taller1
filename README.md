**¿En qué parte usaron Grid y por qué?**

Use Grid principalmente en la sección de productos. Ahí usé cuatro tarjetas de café y quería que quedaran organizadas en varias columnas, todas con un tamaño parecido.

También usé Grid en la sección de Nuestra historia, donde tenemos dos partes, el texto de la historia y el espacio para la imagen. Grid sirvió para colocar estas dos partes una al lado de la otra.

**¿En qué parte usaron Flexbox y por qué?**

Usé Flexbox en la cabecera para colocar el nombre de la cafetería a un lado y el menú al otro. También se usó dentro del menú para poner los enlaces en una sola fila.

Además, se usó Flexbox en el apartado principal para centrar el título, el texto y el botón.
